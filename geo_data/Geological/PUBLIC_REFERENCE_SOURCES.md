# Public Reference Sources — Context Only

The following sources were consulted for high-level context about Indian geological/mining GIS workflows. They are NOT the source of the synthetic mine-specific geometries in this package.

1. Geological Survey of India (GSI) / Bhukosh
   - GSI materials describe geological and geoscientific GIS datasets and the Bhukosh portal.
   - https://gsi.gov.in/

2. GSI National Geoscience Data Repository / Hackathon data description
   - GSI's hackathon page describes geological, geochemical, geophysical, exploration and remote-sensing datasets and GIS-compatible derived data.
   - https://hackathon.gsi.gov.in/login

3. Indian Bureau of Mines (IBM) — GIS / Multi Mineral Leasehold Maps
   - IBM documentation describes integration of mining lease boundaries, geology/topographic layers and GIS-based mining information.
   - https://ibm.gov.in/

4. IBM — National Mineral Inventory
   - IBM describes NMI fields including location, geology, exploration, resources/reserves and other mineral information.
   - https://ibm.gov.in/IBMPortal/pages/National-Mineral-Inventory

5. IBM — Geo-referenced cadastral map requirements
   - IBM documentation describes geo-referenced mining lease maps, DGPS boundary control and GIS-compatible shapefile submission in mining workflows.
   - https://ibm.gov.in/

Public context is intentionally separated from the synthetic corpus. No public source is being represented as providing the generated borehole measurements, synthetic geological intervals, synthetic DEMs, or mine-specific synthetic geometry in this package.
