GeoVault AI — Final Synthetic Demonstration Dataset

This package is intentionally synthetic-friendly: every analytical field is populated with
internally consistent prototype values, while provenance clearly identifies the data as
SYNTHETIC_DEMO. It must not be represented as official CIL/CMPDI data.

Coverage:
5 mines × FY2019-20 to FY2024-25.

Five yearly workbooks:
FY2020-21, FY2021-22, FY2022-23, FY2023-24, FY2024-25.
Each contains all five mines, complete production history, YoY validation, equipment,
safety, environment, operational events and a data dictionary.

YoY formula:
((Current FY Actual Production - Previous FY Actual Production) /
 Previous FY Actual Production) × 100.

FY2019-20 is the baseline, so it has no previous year and therefore no YoY value.
That is the only intentional blank in the master analytical table.

The CMPDI National Coal Portal is used only as a terminology/reference source:
https://coaldashboard.cmpdi.co.in/dashboard.php
